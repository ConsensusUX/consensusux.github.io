# Contributing

## Overview

ConsensusUX is an open source project. Contributions from designers, developers, researchers, and community organizers are welcome.

---

## Ways to Contribute

- **Code**: React / React Native development — web and mobile surfaces, shared packages, and backend
- **Design**: UX research, wireframing, prototyping, and user testing
- **Theory**: Academic research, case studies, and comparative analysis of consensus systems
- **Documentation**: Wiki pages, user guides, and translations
- **Testing**: Community testing, accessibility audits, and game-theoretic analysis of the scoring algorithm

## Contribution Guidelines

- All contributions go through the standard GitHub pull request process
- Feature proposals should reference the theoretical foundations documented in the [Theory](/theory) section
- Code contributions should include tests
- UX changes should include rationale connecting to the [Design Principles](/features)
- Be respectful of the project's commitment to horizontal organisation

---

## Code of Conduct

ConsensusUX is committed to the same principles it builds: equitable participation, informed consent, and collective decision-making. Contributors are expected to engage constructively and respectfully.
